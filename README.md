# Planejador Financeiro Pessoal

Dashboard web simples para controle do orçamento mensal e das despesas ao longo do ano, feito com HTML, Bootstrap e jQuery, com os dados salvos diretamente no navegador (`localStorage`).

## O que o planejador faz

- Permite definir um **orçamento mensal base**.
- Organiza o ano em **12 meses**, cada um em um painel expansível (acordeão).
- Em cada mês, permite **adicionar e remover despesas** com nome e valor.
- Calcula automaticamente o **total de gastos** e o **saldo** de cada mês.
- **Acumula o saldo** de um mês para o próximo, projetando o saldo final do ano.
- Mantém os dados salvos localmente, sem necessidade de servidor ou login.

## Ganhos e benefícios

- **Visão clara e rápida** da saúde financeira mês a mês e no acumulado anual.
- **Simplicidade**: sem instalação, planilhas ou cadastro — basta abrir o arquivo no navegador.
- **Organização das despesas** por mês, facilitando identificar onde o dinheiro está sendo gasto.
- **Feedback visual imediato** (saldo positivo ou negativo em destaque) para decisões rápidas.

## Importância

Ter um controle contínuo do orçamento ajuda a evitar surpresas financeiras, antecipar meses de saldo negativo e planejar melhor os gastos futuros. Por ser leve e visual, o planejador incentiva o hábito de acompanhar as finanças pessoais de forma consistente.
